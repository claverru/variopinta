# User documentation

The repository README is the installation and quick-start entry point. These
guides describe the current public Python surface in more detail:

- [Transform reference](transforms.md): constructors, defaults, policies, and
  output effects.
- [Pipelines and image I/O](pipelines-and-io.md): execution, reproducibility,
  standalone codecs, native sources and sinks, limits, ownership, and GIL
  behavior.

This versioned tree is limited to user-facing documentation.
